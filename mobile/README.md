# Môj Multisport – Android

Súkromná mobilná aplikácia pre produkčné tipy Multisport Betting Engine.

## Čo obsahuje

- dnešné potvrdené tipy a bezpečné `NO BET`,
- sekcie Futbal, Tenis, Basketbal, Hokej, Baseball, MMA a NFL,
- stav modelu: uzavreté tipy, yield a zisk,
- rozlíšenie `EARLY` a `FINAL`,
- automatické obnovenie každých päť minút a potiahnutím obrazovky,
- lokálnu zálohu posledných načítaných dát,
- žiadne dátové API tokeny v telefóne.

## Lokálne spustenie

1. Nainštalovať závislosti v tomto priečinku.
2. Spustiť `npm run android` s otvoreným Android emulátorom alebo pripojeným telefónom.

Push notifikácie a súkromné prihlasovanie budú pridané v ďalšej etape spolu s malou zabezpečenou serverovou vrstvou. Produkčné API kľúče nikdy nepatria priamo do APK.
